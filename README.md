## ✨ Особенности

- 🎮 **Классический roguelike геймплей** - пошаговые сражения, процедурная генерация, permadeath
- 🏰 **15 уровней подземелья** с уникальными боссами каждые 3 этажа
- ⚔️ **Система экипировки** - оружие и броня с возможностью улучшения
- 🧪 **Разнообразные предметы** - зелья, свитки с заклинаниями, ключи, реликвии
- 🏪 **Торговцы и алтари** - покупайте товары и благословляйте экипировку
- 🎵 **Фоновая музыка** с возможностью управления громкостью
- 💾 **Система сохранений** - продолжите игру в любой момент
- 🌫️ **Поле зрения (FOV)** - реалистичный "туман войны"
- 🎯 **Две концовки** - обычная победа и "идеальная победа" (собрать все реликвии)
- 📊 **Статистика** - отслеживание золота, опыта, уровня игрока

## 🚀 Установка

### Требования

- **Go 1.27** или выше
- Терминал с поддержкой UTF-8 и цветов (рекомендуется)
- Аудио устройство (опционально, для музыки)

### Сборка из исходников

```bash
# Клонируйте репозиторий
git clone https://github.com/pandim/Nethack-GO.git
cd Nethack-GO

# Установите зависимости
go mod download

# Соберите бинарный файл
go build -o nethack

# Запустите игру
./nethack
```

### Быстрый запуск

```bash
# Если у вас уже установлен Go
go run .
```

## 🎮 Управление

### Движение

| Клавиша | Действие |
|---------|----------|
| `W` / `↑` | Движение вверх |
| `S` / `↓` | Движение вниз |
| `A` / `←` | Движение влево |
| `D` / `→` | Движение вправо |
| `Q` | Диагональ вверх-влево |
| `E` | Диагональ вверх-вправо |
| `Z` | Диагональ вниз-влево |
| `C` | Диагональ вниз-вправо |
| `Space` | Ждать ход |

### Действия

| Клавиша | Действие |
|---------|----------|
| `I` | Открыть инвентарь |
| `1-9` | Использовать предмет из инвентаря |
| `>` | Спуститься по лестнице |
| `<` | Подняться по лестнице |
| `T` | Торговать с купцом |
| `P` | Молиться у алтаря |
| `O` | Открыть сундук |
| `Shift+S` | Сохранить игру |

### Системные

| Клавиша | Действие |
|---------|----------|
| `M` | Включить/выключить музыку |
| `+` / `-` | Увеличить/уменьшить громкость |
| `?` | Помощь |
| `ESC` | Выход / Подтверждение |

## 🎯 Механики игры

### 🗡️ Боевая система

- **Пошаговые сражения** - вы и монстры действуете по очереди
- **Атака и защита** - урон рассчитывается с учетом экипировки
- **Критическое здоровье** - при HP < 20% персонаж мигает красным

### 🍖 Система голода

- Голод увеличивается с каждым шагом
- При критическом голоде (>800) начинает падать HP
- Используйте зелья и еду для восстановления сытости

### ⚔️ Экипировка

- **Оружие** - увеличивает атаку (ATK)
- **Броня** - увеличивает защиту (DEF)
- **Улучшение** - надевание нового предмета того же типа улучшает текущий (+1 к бонусу)

### 📜 Свитки

- **Свиток карты** - открывает весь этаж
- **Свиток телепортации** - случайное перемещение
- **Свиток молнии** - урон всем монстрам на уровне
- **Свиток изгнания** - уничтожает случайного монстра

### 💎 Реликвии

5 уникальных предметов, выпадающих с боссов (шанс 60%):
- Алмаз (150 золота)
- Золотой кубок (200 золота)
- Корона гоблинов (300 золота)
- Древняя статуэтка (400 золота)
- Осколок звезды (500 золота)

Продавайте их торговцам для получения золота!

### 🏪 Торговцы

- Появляются на уровнях 2, 5, 8, 11, 14
- Покупают реликвии и продают полезные предметы
- **Важно:** при повторном посещении уровня цены удваиваются!

### ⛪ Алтари

- Благословляют экипировку (+2 к бонусу) за золото
- Располагаются на каждом уровне

### 📦 Сундуки

- Требуют ключ для открытия
- Содержат ценный лут

### 🪤 Ловушки

- Наносит 3 урона и телепортирует в случайное место
- Количество ловушек равно глубине уровня

### 👹 Боссы

Каждые 3 уровня (3, 6, 9, 12, 15) вас ждут боссы с уникальными способностями:
- **Регенерация** - восстанавливает 3 HP каждый ход (только в бою!)
- **Двойная атака** - наносит два удара за ход
- **Призыв миньонов** - призывает подмогу каждые 5 ходов

## 🏆 Цель игры

### Обычная победа
1. Спуститесь на 15-й уровень
2. Победите **Короля Бездны** (финальный босс)
3. Подберите **Амулет Бездны**
4. Вернитесь на 1-й уровень

### 🌟 Идеальная победа
Соберите все 5 реликвий и вернитесь с Амулетом! Это даст вам особый статус "Истинной легенды подземелья".

## 📁 Структура проекта

```
Nethack-GO/
├── main.go              # Точка входа
├── go.mod               # Зависимости Go
├── go.sum               # Контрольные суммы
├── music.mp3            # Фоновая музыка
├── README.md            # Этот файл
└── game/                # Игровая логика
    ├── game.go          # Главный контроллер, состояния игры
    ├── player.go        # Игрок, инвентарь, экипировка
    ├── monster.go       # Монстры, ИИ, боссы
    ├── item.go          # Предметы, типы, конструкторы
    ├── level.go         # Базовая структура уровня
    ├── level_gen.go     # Процедурная генерация
    ├── level_spawn.go   # Расстановка объектов
    ├── level_boss.go    # Логика боссов
    ├── level_stairs.go  # Лестницы
    ├── level_fov.go     # Поле зрения (туман войны)
    ├── level_queries.go # Запросы к карте
    ├── level_util.go    # Утилиты уровня
    ├── level_render.go  # Отрисовка уровня
    ├── combat.go        # Боевая система
    ├── interact.go      # Взаимодействие с окружением
    ├── input.go         # Обработка ввода
    ├── render.go        # Отрисовка UI
    ├── audio.go         # Аудиоподсистема
    ├── save.go          # Сохранения/загрузки
    ├── altar.go         # Механика алтарей
    ├── chest.go         # Механика сундуков
    └── merchant.go      # Механика торговцев
```
