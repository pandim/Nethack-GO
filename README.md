## 🚀 Установка

### Требования

- **Go 1.22** или выше (используется современный `math/rand/v2`)
- Терминал с поддержкой UTF-8 и истинных цветов (True Color)
- Аудиоустройство (опционально, для фоновой музыки)

### Сборка из исходников

```bash
# Клонируйте репозиторий
git clone https://github.com/pandim/Nethack-GO.git
cd Nethack-GO

# Установите зависимости
go mod download

# Соберите бинарный файл
go build -o nethack

# Запустите игру
./nethack
```

### Быстрый запуск

```bash
# Если у вас уже установлен Go 1.22+
go run .
```

| `Z` | Диагональ вниз-влево |
| `C` | Диагональ вниз-вправо |

| Клавиша | Действие |

## 🎯 Механики игры

### 🗡️ Боевая система

- **Пошаговые сражения** — вы и монстры действуете по очереди.
- **Атака и защита** — урон рассчитывается с учетом экипировки. Если защита полностью поглощает урон, монстр всё равно наносит минимум 10% от своей атаки (но не менее 1), что предотвращает полную неуязвимость.
- **Критическое здоровье** — при HP ≤ 5 появляется предупреждение о необходимости лечения.

### 🍖 Система голода

- Голод увеличивается с каждым шагом и действием.
- При критическом голоде (>800) персонаж начинает "умирать", а при 1000 наступает смерть от истощения.
- Используйте еду для восстановления сытости.

### ⚔️ Экипировка

- **Оружие** — увеличивает атаку (ATK).
- **Броня** — увеличивает защиту (DEF).
- **Улучшение** — надевание нового предмета того же типа с более высоким бонусом автоматически заменяет старый.

### 📜 Свитки

Одноразовые предметы, которые складываются в стопки:

- **Свиток карты** — открывает весь этаж (снимает туман войны).
- **Свиток телепортации** — случайное перемещение по текущему уровню.
- **Свиток молнии** — наносит урон всем монстрам на уровне.
- **Свиток изгнания** — мгновенно уничтожает случайного монстра.

### 💎 Реликвии

5 уникальных предметов, выпадающих с боссов (шанс 60%) или из золотых сундуков:

- Алмаз (цена продажи: 150 золота)
- Золотой кубок (200 золота)
- Корона гоблинов (300 золота)
- Древняя статуэтка (400 золота)
- Осколок звезды (500 золота)

*Продавайте их торговцам для получения золота!*

### 🏪 Торговцы

- Появляются на уровнях 2, 5, 8, 11, 14.
- Покупают реликвии и продают полезные предметы (зелья, еду, оружие, броню).
- **Важно:** при повторном посещении уровня цены у торговца удваиваются!

### ⛪ Алтари

- Располагаются на каждом уровне.
- Благословляют экипированное оружие или броню (+2 к бонусу) за золото. Стоимость благословения растет с глубиной подземелья.

### 📦 Сундуки

- **Обычные сундуки**: могут содержать зелья, еду или монстра-ловушку.
- **Золотые сундуки**: требуют **Ключ** для открытия. Содержат ценный лут: с высоким шансом (75%) выпадает одна из 5 реликвий, либо свиток (20%), либо золото (5%).

### 🪤 Ловушки

Скрытые опасности, подстерегающие на каждом шагу (количество ловушек равно глубине уровня). Они невидимы до момента срабатывания. При наступании активируется один из трех эффектов:

- **Обычная ловушка (50%)**: наносит 3 урона и телепортирует игрока в случайное место.
- **Ловушка-вор (30%)**: крадет 25% вашего текущего золота.
- **Проклятие (20%)**: снижает уровень зачарования (бонус ATK/DEF) экипированного оружия или брони на 1. Если улучшать нечего, вызывает внезапный приступ голода.

### 👹 Боссы

Каждые 3 уровня (3, 6, 9, 12, 15) вас ждут боссы с уникальными способностями. Они охраняют лестницу вниз, и победить их необходимо для продвижения:

- **Регенерация** — восстанавливает 3 HP каждый ход (активируется только в бою, когда игрок рядом!).
- **Двойная атака** — наносит два удара за ход.
- **Призыв миньонов** — призывает подмогу каждые 5 ходов боя.

### 🚪 Секретные проходы

На 4-м и 9-м уровнях можно найти скрытую лестницу (`≈`), которая позволяет прыгнуть сразу на 2 уровня вниз, минуя промежуточные этажи (и их опасности).

## 🏆 Цель игры

### Обычная победа

1. Спуститесь на 15-й уровень.
2. Победите **Короля Бездны** (финальный босс).
3. Подберите **Амулет Бездны**, который появится на его месте.
4. Вернитесь на 1-й уровень и поднимитесь по лестнице на поверхность.

### 🌟 Идеальная победа

Соберите все 5 реликвий и вернитесь на поверхность с Амулетом! Это даст вам особый статус "Истинной легенды подземелья" и уникальный экран победы.
